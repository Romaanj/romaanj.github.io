Two halves:

- **Design system** — a small set of tokens and patterns (serif display headings, warm ivory ground, a single coral accent) applied consistently across every page. Static output, no client framework, fonts self-hosted.
- **Review pipeline** — a daily arXiv sweep feeds review drafts straight into the site's content collection, so the reading graph updates itself each morning before I've had coffee.
