analysis:
  ko:
    background: 'Post-training quantization(PTQ)은 재학습 없이 사전학습된 LLM의 가중치를 저비트로 압축하는 기법으로, GPTQ 계열의 compensation 기반 방법이 사실상 표준이다. 이 방법들은 Optimal Brain Surgeon 원리를 층별로 적용해, 입력 activation covariance H_X를 layer Hessian의 근사로 써서 양자화 오차를 남은 가중치에 재분배한다. Kronecker-factored 근사(K-FAC) 하에서는 전체 weight Hessian이 H ≈ H_X ⊗ H_G(H_G는 출력 gradient covariance)로 분해되는데, GPTQ류는 H_G = I로 암묵 가정하고 이를 버려왔다.'
    problem: 'LLaMA-2-13B의 Q/K/V/O projection에서 H_G의 대각 성분을 직접 측정하면 출력 채널마다 크기가 자릿수 단위로 다르다(Figure 1a) — 즉 H_G = I 가정은 사실이 아니다. 이는 모든 학생의 답안 배점을 동일하게 매기면서, 실제로는 일부 문항이 훨씬 더 중요한 시험 채점표와 같다. 특히 2-3bit처럼 양자화 오차가 큰 저비트 영역에서 이 잘못된 가정이 재구성 오차를 부풀린다.'
    prior_limits: 'GPTQ는 H_X만으로 column-wise OBS 업데이트를 풀고, GPTAQ는 앞선 layer의 양자화로 인한 input drift를 보정하지만 여전히 H_X에만 의존한다. GuidedQuant는 end-loss gradient saliency로 H_X를 재가중하지만 출력 채널 간 상관 구조는 무시하고, 가장 근접한 선행 연구 YAQA는 동일한 H ≈ H_X ⊗ H_G 분해를 쓰지만 H_G를 costly한 power-iterated Hessian sketch로 별도 LDLQ solver에 접어 넣어야 한다.'
    goal: '기존 GPTAQ solver를 그대로 유지하면서, 단 한 번의 backward pass로 얻은 H_G를 (1) incoherence processing과 (2) sublayer 단위 mixed-precision 할당 두 곳에 싸게 주입하는 것이 목표다. YAQA처럼 solver 자체를 재작성하지 않고도 출력측 정보를 활용해야 한다는 것이 핵심 제약이다.'
    method: '**KronQ**는 두 요소로 구성된다. (1) Bidirectional incoherence processing — 기존에는 입력측에만 적용하던 random rotation을 H_G 기반으로 출력측까지 확장해 입력·출력 양쪽의 가중치 크기 분산을 줄인다. 이 확장에서 H_G는 quantization update 식에서 상쇄되어(cancels), solver 자체는 GPTAQ와 완전히 동일하게 유지된다 — 마치 저울 양쪽에 같은 추를 추가해 무게중심만 옮기고 저울 구조는 바꾸지 않는 것과 같다. (2) tr(H_G)·tr(H_X)로 정의되는 새 sensitivity metric으로 sublayer별 mixed-precision 할당을 수행하는데, 기존 H_X 단독 지표는 Q/K/V처럼 입력 통계가 같은 sublayer를 구분하지 못하지만 이 joint metric은 구분해낸다.'
    key_idea: '출력측 gradient covariance H_G를 "별도로 풀어야 할 새 최적화 문제"가 아니라 "기존 solver에 끼워 넣을 수 있는 상쇄 가능한 보정항"으로 다루는 것이 핵심이다. YAQA가 H_G를 무겁게 근사해 별도 solver로 접어 넣는 것과 달리, KronQ는 H_G가 incoherence 변환 안에서 대수적으로 상쇄되도록 설계해 GPTAQ 효율을 그대로 보존한다.'
    validation: 'LLaMA-2(7B/13B/70B)와 LLaMA-3(8B/70B)에서 weight-only(W4/W3/W2)와 weight+activation(W2A4) 두 세팅 모두 평가했고, group quantization(g=128) 및 Phi-4-mini-instruct 등 최신 모델군에도 별도 표로 검증했다. 비교 대상은 OmniQuant, AWQ, GPTQ, GPTAQ이며, WikiText-2 perplexity와 7개 zero-shot 벤치마크 정확도를 함께 보고한다. H_G의 기여를 분리하는 ablation(incoherence만 제거, mixed-precision만 제거)도 포함한다.'
    results: 'LLaMA-3-70B 2-bit weight-only에서 GPTQ/GPTAQ가 발산하거나 퇴화된 양자화를 내는(WikiText-2 perplexity **2000 초과**) 반면 KronQ는 **7.93**을 기록한다. Group quantization(g=128) W2에서는 GPTAQ의 274.0 대비 KronQ **7.61**로 격차가 더 크고, W2A4(weight+activation)에서는 LLaMA-2-7B 기준 GPTQ 36.74 → KronQ **9.38**까지 낮아진다. 최신 모델군(Phi-4-mini 등) W4/W2 8개 세팅 전부에서 GPTQ/GPTAQ를 이기며, 저비트로 갈수록 격차가 벌어진다.'
    comparison: '동일 H_X만 쓰는 GPTQ/GPTAQ 대비 전 bit-width에서 우위이고, 특히 W2/W3처럼 activation-covariance-only 방법이 급격히 무너지는 저비트 구간에서 이득이 가장 크다. 가장 근접한 YAQA와는 직접 벤치마크 비교표가 제시되지 않으며, YAQA의 costly한 power-iterated sketch 대비 KronQ는 단일 backward pass만 필요하다는 계산비용 차이를 저자들이 강조한다. Mixed-precision ablation(Table 6)에서 KronQ의 joint score가 tr(H_X) 단독 지표보다 더 나은 sublayer 승급 순서를 찾아낸다.'
    significance: 'Q/K/V/O처럼 입력 통계가 동일한 sublayer들을 구분하지 못했던 H_X 단독 sensitivity 지표의 근본적 사각지대를 단일 backward pass 비용으로 메운다는 점에서, PTQ 파이프라인에 거의 무료로 끼워 넣을 수 있는 개선이다. 2-bit 극저비트 영역에서 GPTQ/GPTAQ가 발산하는 실패 모드를 정량적으로 고친다는 점은 서빙 비용 절감에 직접적 함의가 있다(리뷰어 판단).'
    limitations: 'LLaMA-3-70B W2A4처럼 outlier가 유독 큰 설정에서는 KronQ도 완전히 안정적이지 않다고 저자들이 부록에서 인정한다(논문 본문에 명시). H_G 추정에 calibration 데이터의 backward pass가 필요해 forward-only인 순수 GPTQ보다 계산 비용이 약간 늘어나며, 이 오버헤드의 절대 시간은 논문에 정량화되어 있지 않다(논문 내 명시 없음).'
    future_work: '저자들은 KronQ의 incoherence 확장을 QuIP#류의 lattice-based vector quantization과 결합하는 방향, 그리고 H_G 추정을 activation 통계와 함께 online으로 갱신하는 방향을 열린 문제로 언급한다(논문 본문 Discussion 절 기준).'
    resources: '공식 GitHub 저장소(https://github.com/Intelligent-Computing-Lab-Panda/KronQ)가 논문 표지에 명시되어 있으며 curl로 200 응답을 확인했다. COLM 2026 accepted paper로, 코드와 함께 LLaMA-2/3 전 스케일 재현 설정이 공개되어 있다고 저자들이 밝힌다.'
  en:
    background: 'Post-training quantization (PTQ) compresses a pretrained LLM''s weights to low bit-widths without retraining, and GPTQ-style compensation-based methods are the de facto standard. These apply the Optimal Brain Surgeon principle layer-by-layer, using the input activation covariance H_X as a proxy for the layer Hessian to redistribute quantization error onto the remaining weights. Under the Kronecker-factored approximation (K-FAC), the full weight Hessian factorizes as H ≈ H_X ⊗ H_G, where H_G is the output-side gradient covariance — but GPTQ-style methods implicitly assume H_G = I and discard it.'
    problem: 'Directly measuring the diagonal of H_G for the Q/K/V/O projections of LLaMA-2-13B shows output channels vary in magnitude by orders of magnitude (Figure 1a) — the H_G = I assumption is simply false. This is like a grading rubric that scores every question equally when some questions are actually worth far more. The mis-assumption inflates reconstruction error most in the low-bit regime (2-3 bit) where quantization error is already large.'
    prior_limits: 'GPTQ solves the column-wise OBS update using only H_X, and GPTAQ corrects for input drift caused by prior-layer quantization but still depends solely on H_X. GuidedQuant reweights H_X with end-loss gradient saliency but ignores cross-output-channel structure, and the closest prior work, YAQA, adopts the same H ≈ H_X ⊗ H_G factorization but folds H_G into a separate LDLQ solver via costly power-iterated Hessian sketches.'
    goal: 'Keep the existing GPTAQ solver unchanged while cheaply injecting H_G — obtained from a single backward pass — into two places: (1) incoherence processing and (2) sublayer-level mixed-precision allocation. The constraint is to exploit output-side information without rewriting the solver itself, unlike YAQA.'
    method: '**KronQ** has two components. (1) Bidirectional incoherence processing extends the existing input-side random rotation to the output side using H_G, reducing weight-magnitude variance on both input and output dimensions. In this extension H_G cancels out of the quantization update equation, so the solver itself stays exactly GPTAQ — like adding matched weights to both sides of a scale, shifting only the balance point without changing the scale''s mechanism. (2) A new sensitivity metric, tr(H_G)·tr(H_X), drives sublayer-level mixed-precision allocation; whereas the H_X-only metric cannot distinguish sublayers with identical input statistics (e.g. Q/K/V), this joint metric can.'
    key_idea: 'The core idea is treating the output-side gradient covariance H_G not as a new optimization problem to solve separately, but as a cancelable correction term that plugs into the existing solver. Unlike YAQA, which approximates H_G expensively and folds it into a separate solver, KronQ is designed so H_G cancels algebraically inside the incoherence transform, preserving GPTAQ''s efficiency exactly.'
    validation: 'Evaluated on LLaMA-2 (7B/13B/70B) and LLaMA-3 (8B/70B) in both weight-only (W4/W3/W2) and weight-and-activation (W2A4) settings, plus separate tables for group quantization (g=128) and newer model families including Phi-4-mini-instruct. Baselines are OmniQuant, AWQ, GPTQ, and GPTAQ, reported via WikiText-2 perplexity and accuracy on seven zero-shot benchmarks. Ablations isolate the contribution of H_G by removing incoherence-only or mixed-precision-only.'
    results: 'On 2-bit weight-only LLaMA-3-70B, GPTQ and GPTAQ diverge or produce degenerate quantizations (WikiText-2 perplexity **over 2000**), while KronQ achieves **7.93**. Under group quantization (g=128) at W2, GPTAQ reaches 274.0 versus KronQ''s **7.61** — an even larger gap — and at W2A4 (weight+activation) on LLaMA-2-7B, perplexity drops from GPTQ''s 36.74 to KronQ''s **9.38**. KronQ wins all eight W4/W2 settings on newer model families (e.g. Phi-4-mini), with the margin widening at lower bit-widths.'
    comparison: 'KronQ outperforms GPTQ/GPTAQ (which use H_X alone) across all tested bit-widths, with the largest gains precisely where activation-covariance-only methods degrade sharply — W2 and W3. No head-to-head benchmark table against the closest prior work, YAQA, is presented; instead the authors emphasize a compute-cost distinction — KronQ needs only a single backward pass versus YAQA''s costly power-iterated sketches. In the mixed-precision ablation (Table 6), KronQ''s joint score finds a better sublayer upgrade ordering than the tr(H_X)-only metric.'
    significance: 'KronQ closes a fundamental blind spot in H_X-only sensitivity metrics — their inability to distinguish sublayers sharing identical input statistics (Q/K/V/O) — at the cost of a single extra backward pass, making it close to a free upgrade to existing PTQ pipelines. Quantitatively fixing the divergence failure mode of GPTQ/GPTAQ in the extreme 2-bit regime has direct implications for serving-cost reduction (reviewer judgment).'
    limitations: 'The authors acknowledge in the appendix that even KronQ is not fully stable in settings with unusually large outliers, such as LLaMA-3-70B W2A4 (stated in the paper). Estimating H_G requires a backward pass over calibration data, adding compute cost beyond forward-only GPTQ, but the absolute overhead is not quantified in the paper (not stated in the paper).'
    future_work: 'The authors mention combining KronQ''s incoherence extension with QuIP#-style lattice-based vector quantization, and updating the H_G estimate online alongside activation statistics, as open directions (per the paper''s Discussion section).'
    resources: 'The official GitHub repository (https://github.com/Intelligent-Computing-Lab-Panda/KronQ) is listed on the paper''s title page and was verified to return HTTP 200. This is a COLM 2026 accepted paper, and the authors state the code release includes reproduction configs across the full LLaMA-2/3 scale range.'
