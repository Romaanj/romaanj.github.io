analysis:
  ko:
    background: 'Post-training quantization은 LLM을 자원 제약 환경에 배포하는 표준 기법이지만, 그 평가는 거의 전적으로 accuracy와 perplexity에만 의존해 왔다. 이 논문은 이 두 지표가 quantization이 유발하는 행동 변화(behavioral change)를 포착하지 못한다는 것을 보이며, GGUF 계열의 legacy quantization과 K-quantization(Q8_0~Q2_K)을 llama.cpp 기반으로 비교 분석한다.'
    problem: '동일한 perplexity·accuracy를 내는 base 모델과 quantized 모델이 실제로는 서로 다른 개별 예측을 만들어낼 수 있다 — 즉 집계 지표(aggregate metric)가 같다고 해서 두 모델이 "같은 방식으로" 문제를 푸는 것은 아니다. 이는 반 평균 점수가 똑같은 두 학급이 실제로는 완전히 다른 학생들이 정답을 맞혔을 수 있는 것과 같다 — 평균만 보면 이 차이는 보이지 않는다.'
    prior_limits: '기존 quantization 평가는 accuracy(정답률 자체)와 perplexity(다음 토큰 예측의 불확실성)라는 absolute-value 지표에 집중해 왔고, 두 모델의 "결정 자체"가 얼마나 일치하는지, 즉 어떤 개별 샘플에서 base와 quantized 모델이 서로 다른 답을 내는지는 측정하지 않았다. 이 때문에 accuracy가 거의 보존된 것처럼 보이는 중간 bit-width에서도 실제 행동 변화가 은폐될 수 있었다.'
    goal: 'accuracy·perplexity와 독립적으로 base 모델과 quantized 변형 사이의 행동적 일치도를 측정하는 decision-level metric을 도입하고, 이 metric을 attention weight의 구조적 왜곡과 연결해 quantization이 정확히 어디서, 어떻게 모델 행동을 바꾸는지 설명하는 것이 목표다.'
    method: '**Correctness agreement**라는 metric을 제안한다 — 이는 base 모델과 quantized 변형 각각의 correctness label(정답/오답)을 이진 출력으로 삼아 Hamming 비교를 수행하는, 절대 정확도와 무관하게 두 모델의 결정 행동 사이 일치도를 직접 측정하는 해석 가능한 지표다. 이와 함께 quantization을 attention weight 공간에 대한 구조적 연산자(structural operator)로 취급해, 통계적·분포적 지표(skewness, kurtosis, divergence)로 layer별 왜곡을 정량화한다.'
    key_idea: '핵심 통찰은 "정확도가 같다"와 "같은 방식으로 정확하다"를 분리해야 한다는 것이다 — 두 모델의 평균 성능이 같더라도, 어떤 샘플에서 옳고 그른지가 다르다면 이는 근본적으로 다른 모델이다. Query·Key projection이 Value·Output projection보다 일관되게 quantization에 더 민감하다는 발견은, attention의 "무엇에 주목할지 결정하는" 부분이 "그 정보를 어떻게 조합할지 결정하는" 부분보다 낮은 정밀도에 더 취약함을 시사한다.'
    validation: '여러 모델(Mistral-7B, Llama-3.2-3B, Vicuna-7B, Llama-3.1-8B)과 GGUF 계열 quantization 스킴(legacy 및 K-quantization, Q8_0부터 Q2_K까지)에 대해 HellaSwag, Winogrande, ARC 세 벤치마크로 accuracy와 correctness agreement를 함께 측정했다. Attention layer별 평균·개별 통계 비교, layer-wise sensitivity 분석, quantization level 간 비교를 포함한 체계적 실험 설계를 사용한다.'
    results: 'Llama-3.2-3B는 Q8_0에서 Q4_K로 갈수록 agreement가 점진적으로 낮아지다가 Q3_K·Q2_K에서 급격히 떨어져, 저bit quantization이 이 소형 모델의 행동 일관성을 크게 해친다는 것을 보인다. Mistral-7B는 전반적으로 가장 안정적인 성능과 quantization 수준 전반에 걸친 가장 안정적인 accuracy를 유지하는 반면, Vicuna-7B와 Llama-3.1-8B는 중간 수준(Q5_K~Q4_K)에서 오히려 소폭 회복을 보이는 등 완만한 저하 패턴을 보인다. 저비트(2-bit)로 갈수록 비선형적인(non-linear) breakpoint가 나타나며, 이는 accuracy 하락이 매끄럽지 않고 특정 bit-width에서 급격히 꺾인다는 것을 뜻한다.'
    comparison: '이 논문은 새 방법을 제안해 기존 quantizer를 능가하려는 것이 아니라, 기존 legacy quantization과 K-quantization을 correctness agreement라는 새 렌즈로 재평가하는 분석/평가 논문이다. 비교축은 quantization scheme(legacy vs K-quant) × bit-width(8-bit~2-bit) × 모델(4종)의 3차원 그리드이며, 그 결과 Query/Key projection이 Value/Output projection보다 일관되게 더 민감하다는 구조적 패턴이 전 grid에서 재현된다.'
    significance: '우리 리뷰어 렌즈(quantization/압축 평가)에서 볼 때, 이 논문은 "perplexity·accuracy가 보존되면 quantized 모델은 base 모델과 동등하다"는 업계의 암묵적 가정에 직접 반례를 제시한다. Q/K projection이 V/O보다 더 취약하다는 layer-selective 민감도 발견은, 향후 mixed-precision 방법들이 attention 서브레이어를 구분해 다뤄야 한다는 KronQ류 연구의 동기와도 정확히 맞닿아 있다(리뷰어 판단).'
    limitations: '평가가 GGUF/llama.cpp 생태계의 legacy·K-quantization 스킴에 한정되어 있어, GPTQ·AWQ·QuIP류의 compensation/rotation 기반 PTQ에도 동일한 correctness-agreement 하락 패턴이 나타나는지는 이 논문 범위에서 확인되지 않는다(논문 내 명시 없음). 평가 벤치마크도 HellaSwag·Winogrande·ARC 세 개로 제한적이라, reasoning이나 code 생성처럼 quantization에 더 민감할 수 있는 task에서의 correctness agreement는 다루지 않는다.'
    future_work: '저자들은 correctness agreement를 quantization 외의 다른 모델 압축 기법(pruning, distillation)에도 적용하는 방향과, layer-wise sensitivity 분석을 mixed-precision 할당 정책에 직접 연결하는 방향을 향후 과제로 시사한다(논문 Discussion 절 기준).'
    resources: '논문 arXiv 페이지·본문에서 저자 자신의 코드 저장소 링크는 확인되지 않았다(공개 링크 확인 안 됨). 실험은 GGUF 포맷과 llama.cpp 생태계의 공개 quantization 스킴을 사용한다고 명시하지만, 이는 저자들의 자체 코드 릴리스가 아니라 기존 공개 도구의 활용이다.'
  en:
    background: 'Post-training quantization is the standard way to deploy LLMs under resource constraints, but its evaluation has relied almost exclusively on accuracy and perplexity. This paper shows these two metrics fail to capture the behavioral changes quantization induces, comparing GGUF-family legacy quantization and K-quantization (Q8_0 through Q2_K) via llama.cpp.'
    problem: 'A base model and a quantized model with matching perplexity and accuracy can still produce different individual predictions — matching aggregate metrics do not mean the two models solve problems "the same way." This is like two classes with identical average test scores where entirely different students got the right answers — the average alone hides this difference.'
    prior_limits: 'Prior quantization evaluation has focused on absolute-value metrics — accuracy (raw correctness rate) and perplexity (next-token prediction uncertainty) — without measuring how much the two models'' decisions themselves agree, i.e., on which individual samples base and quantized models diverge. This let real behavioral change hide even at moderate bit-widths where accuracy looks nearly preserved.'
    goal: 'Introduce a decision-level metric measuring behavioral agreement between a base model and its quantized variants, independent of accuracy and perplexity, and connect that metric to structural distortion of attention weights to explain exactly where and how quantization changes model behavior.'
    method: 'The paper proposes **correctness agreement**, a metric that treats each model''s correctness label (correct/incorrect) as a binary output and performs a Hamming comparison between the base model and its quantized variant — an interpretable metric that directly measures decision-behavior agreement independent of absolute accuracy. Alongside this, quantization is treated as a structural operator on attention-weight space, quantified via statistical and distributional measures (skewness, kurtosis, divergence) at each layer.'
    key_idea: 'The core insight is that "equal accuracy" must be separated from "correct in the same way" — if two models have the same average performance but disagree on which samples are right or wrong, they are functionally different models. The finding that query and key projections are consistently more sensitive to quantization than value and output projections suggests that the part of attention deciding "what to attend to" is more fragile under low precision than the part deciding "how to combine that information."'
    validation: 'Accuracy and correctness agreement were measured jointly across multiple models (Mistral-7B, Llama-3.2-3B, Vicuna-7B, Llama-3.1-8B) and GGUF-family quantization schemes (legacy and K-quantization, from Q8_0 to Q2_K), using three benchmarks — HellaSwag, Winogrande, and ARC. The experimental design includes average and per-statistic comparisons across attention layers, layer-wise sensitivity analysis, and comparison across quantization levels.'
    results: 'Llama-3.2-3B shows agreement declining gradually from Q8_0 to Q4_K, then dropping sharply at Q3_K and Q2_K, showing aggressive low-bit quantization substantially harms this smaller model''s behavioral consistency. Mistral-7B maintains the strongest overall performance and the most stable accuracy across quantization levels, while Vicuna-7B and Llama-3.1-8B show a more moderate decline with occasional small recoveries at mid-range bit-widths (Q5_K-Q4_K). Non-linear breakpoints emerge at low bit-widths, meaning accuracy degradation is not smooth but bends sharply at specific bit-widths.'
    comparison: 'This is an analysis/evaluation paper, not a new quantizer proposed to beat existing ones — it re-evaluates existing legacy and K-quantization schemes through the new correctness-agreement lens. The comparison axis is a 3-D grid of quantization scheme (legacy vs. K-quant) x bit-width (8-bit to 2-bit) x model (four models), and the structural pattern that query/key projections are consistently more sensitive than value/output projections reproduces across the full grid.'
    significance: 'Through our reviewer lens (quantization/compression evaluation), this paper directly counters the industry''s implicit assumption that "preserved perplexity/accuracy means a quantized model is equivalent to the base model." The layer-selective sensitivity finding — Q/K projections more fragile than V/O — dovetails precisely with the motivation behind mixed-precision work like KronQ, which argues attention sublayers must be treated differently (reviewer judgment).'
    limitations: 'Evaluation is limited to legacy and K-quantization schemes within the GGUF/llama.cpp ecosystem, so whether the same correctness-agreement decline appears under compensation- or rotation-based PTQ (GPTQ, AWQ, QuIP-family) is not confirmed within this paper''s scope (not stated in the paper). The evaluation benchmarks are also limited to three tasks (HellaSwag, Winogrande, ARC), leaving correctness agreement on reasoning or code-generation tasks — potentially more quantization-sensitive — unaddressed.'
    future_work: 'The authors suggest applying correctness agreement to model compression techniques beyond quantization (pruning, distillation), and connecting the layer-wise sensitivity analysis directly to mixed-precision allocation policy, as future directions (per the paper''s Discussion section).'
    resources: 'No author-owned code repository link was found on the arXiv page or in the paper body (no public release verified). The experiments state they use the GGUF format and public quantization schemes from the llama.cpp ecosystem, but this is use of existing public tooling, not the authors'' own code release.'
